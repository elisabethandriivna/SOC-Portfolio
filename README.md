# SOC Analyst Portfolio

This repository contains five hands-on cybersecurity projects focused on SOC analysis and incident investigation.

The projects include Windows Event Log analysis, phishing investigation, network traffic analysis, Splunk investigation, and incident response.

## Projects

### 01 – Windows Security Event Log Analysis
Investigated Windows Security logs to identify suspicious account activity, process execution, failed logons, and privilege changes.

**Tools:** Windows Event Viewer, Windows Security Logs  
**Skills:** Log analysis, event correlation, MITRE ATT&CK

### 02 – Phishing Email Investigation
Analyzed a phishing email, including headers, authentication results, links, and a suspicious attachment.

**Tools:** Thunderbird, email headers  
**Skills:** Phishing analysis, SPF, DKIM, DMARC, IOC collection

### 03 – Wireshark Network Analysis
Analyzed a PCAP file to identify an infected host, suspicious network traffic, and indicators of compromise.

**Tools:** Wireshark  
**Skills:** PCAP analysis, TCP/IP, HTTP, Kerberos, NBNS

### 04 – Splunk Investigation
Investigated suspicious PowerShell execution using Sysmon logs in Splunk.

**Tools:** Splunk, Sysmon, SPL  
**Skills:** SIEM investigation, process analysis, event correlation

### 05 – Incident Response Report
Investigated a Cerber ransomware incident from initial detection to IOC scoping and response recommendations.

**Tools:** Splunk, Sysmon, Suricata, VirusTotal, MITRE ATT&CK  
**Skills:** Incident response, ransomware investigation, IOC analysis, threat hunting
